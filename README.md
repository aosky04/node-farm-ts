# 🌽 node-farm-ts

A simple **Node.js HTTP server** built with **TypeScript** for learning purposes.

It serves product data and HTML pages using templates, provides a small JSON API, and demonstrates basic server-side routing without frameworks like Express.

## 🎯 Learning Goals

- Understand how to use Node’s built-in `http` module.
- Learn to serve and parse data into HTML templates.
- Practice structuring a minimal backend project in TypeScript.
- Return structured JSON data through an API endpoint.
- Parse query parameters and handle simple routes.
